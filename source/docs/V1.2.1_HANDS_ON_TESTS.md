## Found

| # | Area | Finding | Severity | Status |
|---|---|---|---|---|
| 1 | Tuning advisor | "auto" tries Bonsai repos first; llama.cpp can't load them ("unsupported architecture"), and nothing remembers that, so tunes download them again: 16.4 GB of Bonsai files sat in a test home's `_advisor`. | high (disk, time) | **fixed** (outcomes remembered per llama.cpp build, skipped before download; files that can't load are deleted) — the owner's PC has 17.2 GB of them |
| 2 | Overlay | `aero.overlay` keeps running when the server is killed hard (normal quit is fine). | low | noted |
| 3 | Browser / mail | Outlook.com "Sign in" click: snapshot taken mid-redirect (empty page, no sign-in card). | low | noted |
| 4 | Tools-off notice | Two near-identical notices for one request (before and after the reply). | low | **fixed** (one notice) |
| 5 | Sign-in skip | After a skip the model said "sign in in the window that's open", but Aero closes the browser at the end. | medium | **fixed** (skip instruction) |
| 6 | Apps | `app_launch calculator` on a PC without Calculator: "has no launch method Aero can use", unclear. | medium | **fixed** ("doesn't seem to be installed… don't start it another way") |
| 7 | Apps / honesty | The model then ran `Start-Process calc.exe` (a stub with no window) and said "Calculator is open". | high | **fixed** (prompt rule: check the window after run_command) + #6 |
| 8 | Shared learning | The false Calculator claim became a lesson for every model ("Worked: run_command Start-Process calc.exe opened Calculator"). Removed from the owner's install. | high | **fixed** (reflection sees which calls were verified; only proven effects count) |
| 9 | Sign-in card | Names the sign-in host (accounts.google.com) instead of the site asked for (mail.google.com). | low | **fixed** |
| 10 | VRAM dialog | "safety margin.Last time you typed" (missing space). | low | **fixed** |
| 11 | Depth picker | Full still described as "until no one-step move can improve the goal". | low | **fixed** |
| 12 | Tuning advisor | With the model filling the GPU the advisor runs on the CPU, and "auto" picked a 27B there (7.8 tokens/s, minutes per decision). | high | **fixed** (CPU advisors ≤ 4B and ≤ 3 GB; one slower than 20 s per decision is dropped) |
| 13 | Tuning cancel | Cancel took minutes during the advisor exam (requests up to 180 s, no cancel check). | medium | **fixed** (Cancel stops the advisor server at once) |
| 14 | Model search | MLX repos (Apple-only) are labelled "original" like convertible ones. | low | noted |
| 15 | Hindsight | Fails to start on the real install: its banner can't be printed in cp1252 (UnicodeEncodeError '▄'); test homes had UTF-8 forced. | 16 | Permissions | On the owner's install shell commands run without asking, so after the Hindsight failure the model tried to start it by hand with Start-Process (stopped). Owner's own setting; worth a look. | info | noted |
| 17 | Workspaces | Create opened for an image request, but the panel kept showing Memory+: Memory+'s 5-second refresh landed after Create's render and redrew itself over it. | medium | **fixed** (a render for a workspace that is no longer open is dropped); verified live |
