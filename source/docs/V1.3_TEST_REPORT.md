# Aero 1.3: every feature tested on a real PC

Aero 1.3 came out of one night of testing every feature on the owner's PC, fixing what broke, and adding what was
missing. This is what was run, what it found, and which outside projects were considered.

## The PC and the setup

- Windows 11 Pro, a 16-core Ryzen 9, 64 GB RAM, NVIDIA RTX 5080 (16 GB), several monitors.
- A test copy of Aero (its own data folder and ports), never the owner's install. App windows and Aero's browser
  were placed on a side monitor.
- Models:
  - Qwen3.8-27B IQ2_M with its vision projector and MTP drafts: 81,920 context, 102.5 tok/s.
  - Qwen3-1.7B Q8_0 without vision, for the text-only paths (OCR).
- A scripted sweep sends each request through `/api/chat` the way the app does, keeps the history the app keeps
  (assistant messages with their tool calls, tool results), allows approval cards, answers question cards, and
  checks the outcome on disk or in the answer.
- Nothing sent mail, bought anything or touched files outside the test folder.

## What the testing found

| Found | Cause | Fix |
|---|---|---|
| The 27B crashed on its second request (CUDA out of memory) | 1.2.70 added a second llama-server slot (350 MB more on this model); tuning measures one, and this model's tuning filled the card | slots only when they fit the tuning's VRAM limit and what other apps leave; restart with one slot when the load log shows a failed allocation |
| "Type into this box" never typed | the router chose `app_click` and `app_read`; companions weren't followed transitively, so `app_type` was never offered | `router.expand` follows companions all the way; a picked window gets every app tool; pressing a text field says to use `app_type` |
| A click before `app_view` became a "timed-out click" | the traceback under "No app selected" contained "timeout" | no traceback for expected errors; the timeout check reads only the error; the picked window is selected and shown instead |
| The same call 39 times | nothing stopped identical calls with identical results | the third such call isn't run; the model is told to change approach |
| "Replace" added to the old text in a Windows Forms box | WinForms edit classes weren't recognised as edit controls | they are; where only keystrokes work, the result says the old text is still there |
| Ten "old_text not found" in a row in a mod | `edit_file` needed an exact copy (the model copied line numbers and indentation wrongly) and turned CRLF files into LF | line endings kept, copied line numbers ignored, indentation-only differences accepted when there is exactly one place, closest line named |
| No mod could pass its checks | the mod copy left out every folder named `data`, including the bundled library snapshots | only the app folder's own `data/` (and models, engine, venv) are left out |
| A small model repeated Aero's hidden context in its answer | Qwen3-1.7B continued past its answer into `<turn_context>` | the answer is cut there and the stream stopped |
| A recording became pages of text | binary files that decode as cp1252 were shown as text | recordings are never decoded as text; with voice typing they are transcribed |
| "Monitor 1" was the side monitor | mss lists monitors in Windows' order | monitor 1 is the primary, as the tool says |
| No way to make a Word document | no skill or tool; the system Python has no python-docx | `write_docx` (Markdown in, a checked .docx out) |

## Outside projects

Integrated in 1.3:

| Project | Licence | Why |
|---|---|---|
| ggml-org/whisper.cpp + OpenAI Whisper base (8-bit) | MIT / MIT | voice typing and transcripts on the CPU, same family as llama.cpp, official builds with published checksums; 0.55 s for a 5 s sentence |
| pywinrt (`winrt-*` packages) for Windows.Media.Ocr | MIT | OCR with nothing to download (about 1 MB of bindings, Windows' own engine and languages); 40 ms per image |

Considered and left for later:

| Project | Licence | Why not now |
|---|---|---|
| EAGLE-3 drafts (llama.cpp `--spec-type draft-eagle3`) | per model | Aero already reads `eagle3-` draft files; matching drafts aren't published for most models yet |
| sherpa-onnx (speech in and out) | Apache-2.0 | whisper.cpp covers speech-to-text with less to install; text-to-speech can follow |
| Docling, MarkItDown | MIT | Aero's own converters already read PDF, Office, HTML and notebooks; OCR now covers scans |
| LanceDB + llama-server embeddings | Apache-2.0 | a per-folder search index is a bigger feature than a night allows |
| RapidOCR | Apache-2.0 | needs onnxruntime and OpenCV (about 60 MB); Windows OCR needs neither; a candidate for macOS and Linux |
| BFCL, Inspect AI | Apache-2.0, MIT | Aero's tuner already runs a BFCL sample |
| llama-swap | MIT | model switching through Aero itself is how Aero works |

Rejected for licence: Piper (GPL), OmniParser weights (AGPL), Meilisearch (BUSL parts), Logseq, Joplin and Trilium
(AGPL).
