# Aero 1.1 test matrix

Classes: **unit** (pure code), **mocked** (real Aero code with a scripted model, fake process list, simulated
sessions or a fake llama-server), **live** (a real desktop, browser or OS API on the test PC), **hardware** (a real
model on a real GPU), **CI** (GitHub Actions on Windows Server 2025, Ubuntu 24.04 and macOS 15), **NOT RUN**.

Commands run from `source/`. Live checks: `set AERO_LIVE_UI=1` (Windows desktop) or `set AERO_LIVE_BROWSER=1`
(Playwright + Edge/Chrome). Test PC: Windows 11 Pro build 26200, Python 3.12 (see V1.1_BASELINE.md).
